# Forma: боевой сервер

Что получится: ваш адрес `https://app.ваш-домен.ru` с приложением и сервером, база данных с ежедневными копиями, HTTPS и push-уведомления. Всё поднимается одной командой.

## Что нужно от вас (4 шага, около часа)

**Шаг 1. Домен.** Нужен адрес, с которого открывается приложение. Если у вас уже есть домен сайта «Вершинин Фитнес», используйте поддомен, например `app.вашдомен.ru`. Если нет, купите домен у любого регистратора (reg.ru, nic.ru, Timeweb), обычно 200–500 ₽ в год. Менять адрес потом нельзя без потери данных на телефонах, поэтому выберите сразу.

**Шаг 2. Сервер в Yandex Cloud** (данные россиян по закону должны храниться в России).
1. Зарегистрируйтесь на cloud.yandex.ru, создайте платёжный аккаунт (карта или ИП).
2. Ключ для входа на сервер. На Mac откройте «Терминал», выполните `ssh-keygen -t ed25519` (три раза Enter), затем `cat ~/.ssh/id_ed25519.pub` и скопируйте вывод целиком.
3. Compute Cloud → «Создать виртуальную машину»: образ Ubuntu 24.04 LTS; платформа Intel Ice Lake, 2 vCPU с гарантированной долей 20%, 2 ГБ RAM; диск SSD 20 ГБ; публичный адрес «Автоматически»; логин `forma`, вставьте ключ из пункта 2. Ориентир по цене 1 000–2 000 ₽ в месяц, точнее покажет калькулятор.
4. После создания: VPC → «IP-адреса» → у адреса вашей машины включите «Сделать статическим» (иначе адрес сменится при перезапуске). Проверьте, что в группе безопасности открыты входящие порты 22, 80, 443.
5. Скопируйте публичный IP машины.

**Шаг 3. Запись в DNS.** У регистратора домена создайте запись типа **A**: имя `app` (или то, что выбрали), значение: IP из шага 2. Подождите 5–30 минут.

**Шаг 4. Установка.** В «Терминале» на Mac:
```
ssh forma@ВАШ_IP
sudo bash -c "$(curl -fsSL https://raw.githubusercontent.com/vershininfit/forma-app/main/deploy/setup.sh)" _ app.вашдомен.ru вы@почта.ru
```
Скрипт сам поставит всё нужное, создаст секреты и запустит сервер. Закончится строкой `Сервер отвечает`. Если домен ещё не готов, он так и скажет, просто повторите команду позже.

Затем создайте код тренера (придумайте свой, от 8 символов, никому не показывайте):
```
sudo bash /opt/forma/repo/deploy/coach-code.sh add "Валерий" 3
```
Число 3 означает, что кодом можно войти с трёх устройств (телефон, планшет, запасной).

**Что сделаю я после шага 4:** вы сообщаете адрес, я проверяю сервер снаружи, прохожу сценарии тренер–клиент и push на боевом адресе.

## Первый вход на iPhone
1. Safari → `https://app.вашдомен.ru` → «Поделиться» → «На экран “Домой”».
2. Откройте приложение с экрана «Домой». Профиль → «Связь с тренером» → введите код тренера. Теперь вы тренер.
3. В профиле включите «Push-уведомления» и нажмите «Проверить».
4. Клиент: ставит так же, в профиле вводит код, который у вас в профиле («Код для клиентов»).

Данные из прежней версии на github.io на новый адрес сами не переезжают: в старой версии «Профиль → Скопировать копию данных», в новой «Восстановить из копии».

## Повседневное
| Что | Команда на сервере |
|---|---|
| Обновить приложение | `sudo bash /opt/forma/repo/deploy/update.sh` |
| Состояние | `docker compose --project-directory /opt/forma -f /opt/forma/repo/deploy/docker-compose.yml ps` |
| Логи сервера | то же, но `logs --tail=100 api` |
| Список и отзыв кодов тренера | `coach-code.sh list`, `coach-code.sh revoke 1` |
| Копии базы | папка `/opt/forma/backups`, раз в сутки, хранятся 14 дней |
| Восстановить из копии | `sudo bash /opt/forma/repo/deploy/restore.sh /opt/forma/backups/forma-ДАТА.sql.gz` |

## Надёжность и безопасность
- Включите в Yandex Cloud расписание снимков диска (Compute Cloud → Диски → Расписания): это вторая независимая копия, на случай потери машины. Копии базы лежат на том же диске, что и база.
- Файл `/opt/forma/.env` содержит секреты. Сохраните его копию в надёжном месте: без него пользователи выйдут из аккаунтов, а push придётся включать заново.
- Сервер не хранит пароли: вход по устройству, роль тренера выдаёт только ваш код (в базе только его хеш), клиент видит тренеру данные только после своего согласия, при отзыве данные клиента удаляются.
- Закон о персональных данных (152-ФЗ): вы как ИП оператор данных клиентов. Нужны политика обработки данных на сайте и уведомление Роскомнадзора. Это не юридическая консультация, уточните у юриста.

## Если что-то не так
- Сайт не открывается, сертификат не выдаётся: проверьте запись A (`ping app.вашдомен.ru` должен показать IP сервера) и открытые порты 80 и 443.
- Приложение открывается, но «нет связи»: `curl https://app.вашдомен.ru/health` должен ответить `{"ok":true}`; иначе смотрите логи `api`.
- Нет push на iPhone: приложение должно быть добавлено на экран «Домой», iOS 16.4 или новее, уведомления разрешены в Настройках.
