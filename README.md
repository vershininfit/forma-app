# Forma

PWA: тренировки, питание, прогресс. Открывается на iPhone через Safari → «Поделиться» → «На экран Домой».

Обновление: `index.html` всегда берётся с сети, правки появляются при следующем открытии (1–2 мин после публикации).

## Данные о продуктах и лицензии
- `data/ru_products.json`: выгрузка Open Food Facts (Россия, Беларусь, Казахстан), лицензия ODbL 1.0 / DbCL 1.0, атрибуция «Open Food Facts contributors». Держится отдельным слоем, не смешивается с собственным справочником.
- `data/base_products.json`: справочник Forma (обычные продукты и блюда без бренда), собственные данные.
- `tools/refresh_off.py`: обновление базы из свежей выгрузки OFF (запускать на компьютере с доступом к huggingface.co).

## Карта нагрузки (`loadmap/`)
Слои для женской фигуры: `loadmap/f/base.png` и по 4 слоя на каждую из 11 групп (`gl_high.png` и т.д., 768×1152). Правила: нагрузка группы = подходы × доля группы из каталога; красным первая группа, жёлтым вторая, синим третья; группа меньше 5% не красится; нагрузка по всему телу (топ-3 ≤ 60% и пять групп от 8%) — всё золотом. Реализовано в `work` (`lmLevels`), эталон на Python и JS: `loadmap/runtime_map.py`, `loadmap/load_map.js`, правила в `loadmap/manifest.json`. Мужская фигура: пока прежняя схема.
