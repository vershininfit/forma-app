# Ассистент тренера в конструкторе (этап 1)

Строка «Надиктуйте или вставьте тренировку» в конструкторе. Разбор работает на телефоне, без сети и внешних сервисов.

- `aib.js` — движок: числа словами, подходы × повторы, вес, время, отдых, суперсеты, круги, дни, сопоставление с каталогом (словарь сленга, базовый вариант, история тренера, нечёткий поиск), уверенность, замены.
- `aib-ui.js`, `aib.css` — интерфейс в кадре «Тренировки»: лист ввода, микрофон (распознавание браузера, иначе диктовка клавиатуры), черновик, добавление, «Вернуть», обучение на выборе тренера (`set.aia`).
- `build.js` — встраивание в `index.html`: `node tools/aib/build.js <исходный index.html> <выход>` (из версии без ассистента).
- Тесты: `node test.js`, `node test2.js` (сопоставление, 117 фраз), `node test4.js` (разбор чисел и голоса). Нужен `fcat.json` рядом: каталог из `index.html` (`var FCAT=`).

Данные: у упражнения в тренировке необязательные поля `alts` (до 2 замен) и `src` (исходная строка).
